# Product Design and Frontend Standards

## Design approach

- Design like an experienced product designer, not an AI website generator.
- Research relevant real-world products before major UI decisions.
- Prefer functional clarity, strong hierarchy and consistency over decoration.
- Avoid generic gradients, excessive glassmorphism, oversized headings and unnecessary cards.
- Do not copy Apple interfaces blindly. Adapt their principles to professional web applications.

## Before implementation

- Inspect the existing application and its design system.
- Understand the users and their primary tasks.
- Study relevant design references.
- Establish layout, typography, spacing, colours and interaction patterns before coding.

## Implementation

- Reuse existing components and design tokens.
- Use the existing React, Tailwind and shadcn conventions.
- Build responsive layouts and realistic loading, empty, error and success states.
- Avoid unnecessary dependencies and duplicated components.

## Visual quality

- Check the actual rendered UI, not just the source code.
- Test desktop, tablet and mobile layouts.
- Check alignment, spacing, typography, contrast and consistency.
- Fix visual issues before declaring the task complete.

## Important

- Do not redesign unrelated parts of the application.
- Do not change existing functionality just to improve appearance.
- Do not claim visual testing was completed unless it was actually performed.
